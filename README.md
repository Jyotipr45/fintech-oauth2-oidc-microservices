# Fintech OAuth 2.0 / OIDC Microservices Platform

Banking microservices reference platform demonstrating enterprise-grade **OAuth 2.0**, **OpenID Connect** and
**asymmetric RS256 JWT** authentication and authorization.

**Stack:** Java 17 · Spring Boot 3.4 · Spring Security 6 · Spring Cloud Gateway · Keycloak · PostgreSQL 16 · Redis · Docker Compose

Active development happens on the `feat/oauth2-oidc-security-architecture` branch.
